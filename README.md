## 📖 Overview

This project demonstrates the integration of the Shodan API with Wazuh SIEM to enrich security alerts with external threat intelligence.

When a Wazuh alert is generated, the custom Python integration automatically queries the Shodan API for additional information about the detected IP address.

The project provides a practical example of Security Operations Center (SOC) automation using Python, Linux, and Wazuh.
